Student Management System Using Singly Linked List

About My Project

This is my second project developed using C programming. The main aim of this project is to manage student details using a Singly Linked List.

In this project, I used dynamic memory allocation and linked list concepts to store and manage student records.

Features

- Add new student details.
- Display all student records.
- Search student details.
- Update student information.
- Delete student records.

Concepts Used

- C Programming
- Singly Linked List
- Structures
- Pointers
- Dynamic Memory Allocation
- Functions

How to Compile and Run

./student

What I Learned

- How to create and manage nodes.
- How pointers work in linked lists.
- How to perform insertion and deletion operations.
- How to allocate and free memory dynamically.
- How to manage student records using data structures.

Conclusion

Through this project, I improved my knowledge of data structures, pointers, and dynamic memory allocation in C programming.
